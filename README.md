# Colégio Dimensão (protótipo)

React + Vite.

    npm install
    npm run dev      # desenvolvimento
    npm run build    # gera dist/

Deploy na Vercel: importe o repositório (preset Vite, build `npm run build`, saída `dist`).

Dados provisórios (telefone, WhatsApp, e-mail, horário): `src/config.js`.
Textos de história, missão e níveis: `src/App.jsx`. Fotos: `src/assets/`.
